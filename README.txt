FRAIS KM V2

Cette V2 ajoute :
- compte utilisateur avec e-mail + mot de passe
- profil prénom/nom
- sauvegarde des trajets dans Supabase
- statistiques mensuelles et annuelles
- historique par année/mois
- modification/suppression
- GPS, calcul de distance et inversion départ/arrivée

Fichiers :
- index.html
- app.js
- style.css
- config.js
- supabase_setup.sql
- manifest.webmanifest

IMPORTANT :
1. Créer un projet Supabase.
2. Exécuter supabase_setup.sql dans SQL Editor.
3. Copier l'URL du projet et la Publishable key dans config.js.
4. Envoyer ces fichiers dans le dépôt GitHub Pages.
5. Ne jamais mettre une clé secret/service_role dans config.js.
